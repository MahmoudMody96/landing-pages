النشر والإصدار

        
ما الذي سينشر لو أصدرت الآن — قبل أي git add -A على فرع يتيم

      

      

    


    

      

    


    

      
 إصدار من اللوحة (ينفّذ tools/release.sh)

      
يشغّل البوابات أولاً ويرفض الشجرة المتسخة — نفس الأمان اليدوي. النشر على Coolify بعده يدوي (زر Redeploy أو API) لأن التوكن لا يُخزَّن هنا أبداً.

      

      

      

    


    

      
 نشر على Coolify (من اللوحة)

      
يعمل فقط لو COOLIFY_TOKEN مضبوط في بيئة الحاوية — وإلا ستظهر رسالة بالنشر اليدوي.

      

        
        
      

      

    


    

      
 أوامر الإصدار (يدوية — نسخ ولصق)

      
git checkout -q --orphan rel-tmp && git add -A && \
git commit -q -m "Release: <وصف>" && \
git push -q -f public rel-tmp:main && git checkout -q main && git branch -D rel-tmp

      
⚠️ git add -A على فرع يتيم بينشر كل ملف غير متجاهَل على ريبو عام. راجع القائمة فوق قبل أي إصدار.
